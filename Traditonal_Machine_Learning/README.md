# 🧠 Traditional Machine Learning Projects

This directory contains a collection of **classical machine-learning projects** that cover
different problem types such as **Regression**, **Classification**, and **Clustering**.  
Each sub-folder is self-contained with notebooks, datasets (where licensing allows),
and any supporting scripts or saved models.

---

## 📂 Structure


| Folder | Description |
|--------|-------------|
| **Regression/** | Projects focused on predictive modeling of continuous targets|
| **Classification/** | Binary and multi-class classification examples |
| **Clustering/** |Unsupervised learning and customer segmentation projects |
| **requirements.txt** | Common dependencies for running these notebooks/apps |



## ✨ About
- **Purpose:** Provide practical, end-to-end implementations of traditional ML techniques.
- **Organization:** Projects are grouped only by task type, so you can add or update projects
  without changing this README.
- **Independence:** Each project has its own notebook(s) and, where needed, a local README or
  embedded markdown cells describing data, steps, and results.

---

## 🚀 How to Run
1. From the repository root, install shared dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Open the notebook of interest, for example:

   ```bash
   Regression/Black Friday/Black Friday ML  Simple EDA, Strong Results.ipynb
   ```
   and run it in Jupyter or VS Code.

   


## 🛠 Tech Stack

- **Languages:** Python 3.x

- **Typical Libraries:** pandas, numpy, scikit-learn, matplotlib, seaborn, TensorFlow, PyTorch, Streamlit

- **Tools:** Jupyter Notebook, VS Code Dev Containers, Git


## 📜 Notes

- This is a living folder: new notebooks and experiments are added over time.

- Datasets are included only when licensing allows; otherwise instructions are provided inside the notebook for downloading data
