# 🧩 Data Science Projects Collection

A central repository containing a growing set of **Machine Learning** and **Deep Learning** projects.  
Each folder is self-contained with notebooks, datasets (where allowed), and any required assets.

---

## 📂 Repository Structure

| Folder | Description |
|--------|-------------|
| **Traditonal_Machine_Learning/** | Classical ML projects covering Regression, Classification, and Clustering. Each project includes EDA, feature engineering, model training, and evaluation. |
| **Deep_Learning/** | Experiments with Artificial Neural Networks (TensorFlow & PyTorch), including tabular, image, and customer-behavior use-cases. |
| **requirements.txt** | Common Python dependencies for quick environment setup. |
| **.devcontainer/** | VS Code container configuration (optional for development). |



---

## ✨ About
- **Purpose:** Provide a single location for all personal data-science experiments and end-to-end projects.  
- **Organization:** Projects are grouped only by *type of approach* (traditional ML vs. deep learning) so new work can be added without changing this README.  
- **Independence:** Each sub-folder is self-documented (via its own README or notebook markdown) and can be explored individually.

---

## 🚀 How to Use
1. **Clone the repository**
   ```bash
   git clone https://github.com/ahmedebrahim12/Data-secince-projects-main.git
   cd Data-secince-projects-main
   ```

2. **Install common dependencies**



```bash
pip install -r requirements.txt
```
    

3. **Explore**

- Browse to either `Traditonal_Machine_Learning/` or `Deep_Learning/`.

- Open the relevant notebook (.ipynb) or script (.py) to review code and results.

## 🛠 Tech Stack

- **Languages:** Python 3.x

- **Typical Libraries:** pandas, numpy, scikit-learn, matplotlib, seaborn, TensorFlow, PyTorch, Streamlit

- **Tools:** Jupyter Notebook, VS Code Dev Containers, Git
